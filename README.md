# LearnSTM32

Personal STM32 learning projects based on STM32F103C8T6.

## Environment

- MCU: STM32F103C8T6
- Core: ARM Cortex-M3
- IDE: Keil uVision5
- Library: STM32 Standard Peripheral Library

## Projects

- `2-1_STM32_Template`  
  Basic STM32 project template.

- `3-1_LED_Blink`  
  Basic GPIO output and LED blinking.

- `3-2_LED_Water_Light`  
  LED water-light effect.

- `3-4_Button_Control_LED`  
  Button input and LED control.

- `3-5_Light_Sensor_Control_LED`  
  Light sensor input and LED control.

- `4-1_OLED_Screen`  
  OLED display control.

- `5-1_Break-Beam_Infrared_Sensor_Counter`  
  Infrared sensor counter using external interrupts.

- `5-2_Rotary_Encoder_Counter`  
  Rotary encoder counting using EXTI interrupts.

## Current Topics

- GPIO
- EXTI
- AFIO
- NVIC
- Interrupts
- Rotary encoder
- OLED
